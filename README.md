# Time-Varying Block Coherence
This toolbox implements an approach that extends Geweke’s linear-dependence measures into the time–frequency domain.

It combines block coherence with time-varying vector autoregressive (TV-VAR) modeling to analyze multivariate interactions.

## Features
- Time–frequency analysis of multivariate signals
- Assessment of redundant and synergistic interactions
- No assumption of specific probability distributions
- Based on linear dependence measures

## Structure
- **Simulation script**: runs the simulations used to demonstrate and validate the proposed method  
- **Functions folder**: contains the core functions implementing the time–frequency and TV-VAR analysis

## Purpose
The toolbox is designed to study dynamic multivariate relationships whose interactions evolve over time and frequency.
